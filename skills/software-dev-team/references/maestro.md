# Maestro 适配

本 Skill 管专业能力与任务边界，官方 Maestro 管需要编排时的 Session/Run 生命周期。用户说目标即可，AI 选择当前安装包提供的真实入口。

## 自动准备与路由

先按 [运行环境](runtime.md) 执行 `ensure`，保存实际版本。读取回执 `router_skill` 指向的官方 `maestro-next` 正文，按它选择必要流程；普通问答或清楚的小改不强制走完整编排。

需要时再加载同版本的 `maestro`、`maestro-ralph` 或其他官方 Skill。回执 `skill_root` 包含这些入口。角色库不复制上游路由表、完成命令或状态协议，随官方包更新消费其实际说明。

官方正文中 `@~/.maestro/workflows/`、`prepare/`、`ref/` 等资源定位到回执 `managed_home` 下的对应目录；读取包内资源，保持上游正文与协议不变。调用 CLI 使用本包的 `run --version` 入口，它仅对子进程指定相同的托管目录。

## 已有任务

已有 Session/Run 时沿用其身份、合同、上游产物和当前固定版本，不从目录时间或相似历史猜当前目标。任务中收到新版本检查结果也不切换执行版本。

本库的任务卡仅在缺少上游合同字段时补充，不另造完成协议、不手写官方状态 JSON，不把角色说明当作推进阶段的授权。

## 分工、环境与迁移

官方流程要求的成员能力与当前宿主能力分别核对；角色不会安装或授权外部模型账户。调用外部 CLI 前确认实际目的地与允许源码内容。

仅分析与规划时，在初始目标和合同中限制阶段，到计划结束；不因默认闭环自行执行产品变更。

自动更新软件包不自动升级项目状态。若官方要求迁移，先核对当前版本帮助和对应升级 Skill，生成实际预览并遵守备份/授权要求。不要把软件包更新、资源准备和项目状态迁移称为同一个结果。
